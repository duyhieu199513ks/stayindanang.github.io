Lantern evenings & heritage streets

Hoi An

Allow 1–2 days

Walk the old town, try cao lau and leave time for a relaxed riverside evening. Add a countryside cycling trip if the weather allows.

A useful planning tip

Visit early for quieter streets; check current old-town ticket rules.
