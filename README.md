# Stay in Da Nang — static travel website

## GitHub Pages
Repository: `duyhieu199513ks/stayindanang.github.io`.
In **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)** and save.
The expected project-site URL is https://duyhieu199513ks.github.io/stayindanang.github.io/.
Internal links and assets use relative paths so nested blog pages work under this subpath.
Canonical URLs, sitemap and robots.txt point to the project-site URL. No custom domain is configured.

## Local development
Run `python3 -m http.server 8001` from the repository root.
No package dependencies or build step are needed. The original ZIP is retained as an archive;
the HTML, CSS and JavaScript files at the repository root are the current source.

## Content
The language selector provides translated navigation and introductions in English, Vietnamese,
Simplified Chinese, Japanese, Korean, Russian, Thai and Hindi. Full blog articles are in Vietnamese.
External photos are illustrative and use image-error fallbacks. Offer links are discovery sources,
not verified active discounts. Check legal notices and contact details before promotion.
